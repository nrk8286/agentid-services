# GPTMarketPlus logo assets

This directory contains the initial GPTMarketPlus logo family. The system uses
the existing site palette and a shared symbol: a geometric `G`, an upward market
signal, and three connected AI nodes.

## Production-ready PNGs

- `gptmarketplus-logo-primary-web.png` — full-color horizontal logo for light backgrounds.
- `gptmarketplus-logo-white-web.png` — one-color horizontal logo for dark backgrounds.
- `gptmarketplus-icon-512.png` — square transparent master for app and social use.
- `gptmarketplus-icon-192.png` — PWA and application icon.
- `gptmarketplus-icon-64.png` — high-density favicon or compact UI mark.
- `gptmarketplus-icon-32.png` — standard favicon-size mark.

## Source PNGs

- `gptmarketplus-logo-primary.png`
- `gptmarketplus-logo-white.png`
- `gptmarketplus-icon.png`

The `*-chroma.png` files are the original generated sources retained for future
re-matting. Production-ready files have transparent backgrounds.

## Palette

- Midnight navy: `#06111d`
- Electric sky blue: `#71d6ff`
- Mint: `#6df0c6`
- Off-white: `#eef6ff`

Use the primary logo on white or pale neutral backgrounds. Use the white logo on
the site's midnight navy surfaces. Keep clear space around the mark equal to at
least one network-node diameter.
