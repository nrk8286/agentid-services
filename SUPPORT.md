# Support

- Product, billing, or engagement questions: [GPTMarketPlus contact](https://gptmarketplus.com/contact)
- Public software defects and feature requests: [GitHub issues](https://github.com/nrk8286/agentid-services/issues/new/choose)
- Security vulnerabilities: [private vulnerability reporting](https://github.com/nrk8286/agentid-services/security/advisories/new)
- Service status: [Worker health](https://gptmarketplus.com/api/agents/health) and [AI search status](https://gptmarketplus.com/api/genai/status)

Do not include API keys, access tokens, payment details, customer records, or private logs in public issues.
